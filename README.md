This project is a simple website created using HTML, CSS, and JavaScript. It demonstrates basic web development concepts, including webpage structure, styling, and interactive functionality. The project was developed to practice creating, organizing, and managing website files using Git and GitHub.
How to Run/View the Project
1. Clone or download the repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open product.html in a web browser to view the website.
   Main Features
   HTML structure for webpage content.
   CSS styling for layout and appearance
   JavaScript functionality for interactive elements.
   Organized project files and folders.
   Git version control with commit history.
